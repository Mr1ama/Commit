# Каталог настольных игр

Небольшое консольное приложение на Python, которое выводит список настольных игр и их жанры.

## Возможности

- хранение списка игр в виде словарей;
- вывод порядкового номера игры;
- отображение названия игры;
- отображение жанра игры.

## Структура проекта

```text
Begin/
├── main.py       # запуск приложения и список игр
├── games.py      # функция вывода каталога
├── README.md     # документация проекта
└── .gitignore    # исключения Git
```

## Требования

- Python 3.13 или более новая версия Python 3;
- Git — только если нужно работать с репозиторием.

Приложение использует только стандартные возможности Python и не требует установки дополнительных пакетов.

## Запуск

Откройте PowerShell в каталоге проекта и выполните:

```powershell
python main.py
```

В Windows также можно указать полный путь к интерпретатору Python:

```powershell
& C:/Users/lamin/AppData/Local/Microsoft/WindowsApps/python3.13.exe "C:/Не нужное/Begin/main.py"
```

## Пример вывода

```text
== Каталог настольных игр ==
1. Каркассон
Жанр: Стратегия
2. Диксит
Жанр: Воображение
```

## Данные игры

Игры задаются в файле `main.py` в списке `games`:

```python
games = [
    {
        "name": "Каркассон",
        "genre": "Стратегия"
    },
    {
        "name": "Диксит",
        "genre": "Воображение"
    }
]
```

Для добавления новой игры добавьте в этот список ещё один словарь с ключами `name` и `genre`.
